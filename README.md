# 歪歪战场 WOBBLE WAR

![歪歪战场](feature.png)

软趴趴的几何小人，打晕、抓起、扔下去。最多 4 人联机乱斗。

## 安卓安装说明
1. 下载 `wobble-war.apk`
2. 打开下载的文件；如果提示「禁止安装未知来源应用」，点「设置」打开「允许此来源」
3. 返回点「安装」

安装包只申请「网络」（联机）和「震动」两个权限。游戏免费，没有广告，没有真钱购买。

这个仓库只用来发布安装包。
